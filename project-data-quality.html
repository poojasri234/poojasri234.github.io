02 — Data Quality & Governance

Business problem

Improve data reliability across reporting pipelines to increase trust in dashboards.

Data

Summary of datasets, quality issues, ranges and sample counts.

Process

Profiling → cleaning → validation tests → monitoring.

Key findings

  • Missing joins caused 18% record loss in critical reports.
  • Inconsistent timestamps led to misaligned aggregates.

Recommendation

Introduce automated validation checks and a documented ETL contract.
